# GitHub Releases & Distribution

## 1. Release Assets

Every tagged release produces the following distributables on GitHub Releases:

1. `GSTReconciler-Setup-vX.Y.Z.exe`: Standard Windows installer with desktop shortcuts and uninstaller.
2. `GSTReconciler-Portable-vX.Y.Z.zip`: Portable standalone directory bundle (requires no installation).
3. `SHA256SUMS.txt`: Cryptographic checksums of all release binaries for integrity verification.
4. `release_notes.md`: Detailed changelog highlighting new features, improvements, and fixes.
