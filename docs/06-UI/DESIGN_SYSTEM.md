# UI Design System

## 1. Professional Financial Design Language

The visual design prioritizes legibility, financial clarity, and high-density information architecture over decorative distraction.

### Color Palette

| Token Name | Hex Code | Purpose |
|---|---|---|
| `bg-primary` | `#0f172a` (Slate 900) | App root background |
| `bg-surface` | `#1e293b` (Slate 800) | Card and table backgrounds |
| `bg-elevated` | `#334155` (Slate 700) | Hover states and modals |
| `text-primary` | `#f8fafc` (Slate 50) | Primary typography |
| `text-secondary` | `#94a3b8` (Slate 400) | Metadata, headers, subtitles |
| `accent-primary` | `#3b82f6` (Blue 500) | Primary action buttons, selection indicators |
| `status-matched` | `#10b981` (Emerald 500)| Perfect match status badge |
| `status-diff` | `#f59e0b` (Amber 500) | Matched with difference badge |
| `status-missing-a`| `#ef4444` (Red 500) | Missing in Source A (ITC at risk) |
| `status-missing-b`| `#8b5cf6` (Purple 500) | Missing in Source B (Unclaimed ITC) |
| `status-duplicate`| `#ec4899` (Pink 500) | Duplicate records |

---

## 2. Typography & Hierarchy

* **Font Family**: Segoe UI, Inter, or system native sans-serif.
* **Header**: 20px / Semibold
* **Card Titles**: 14px / Medium / Uppercase tracking
* **Table Data**: 12px / Monospace font for amounts and GSTINs (`Consolas`, `Cascadia Code`).
