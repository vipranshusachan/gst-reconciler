# Application Screen List

| Screen ID | Screen Name | Description & Key Controls |
|---|---|---|
| `SCR-01` | **Dashboard** | Executive overview, KPI cards, ITC risk summary, discrepancy breakdown chart, quick action buttons ("New Reconciliation", "Load Demo Data"). |
| `SCR-02` | **Import Wizard** | 4-step wizard: (1) Select Files, (2) Auto Column Mapping & Preview, (3) Configure Tolerances, (4) Progress Bar & Execute. |
| `SCR-03` | **Issue Explorer** | High-density virtualized data grid with status filter pills, search input, sortable columns, and review actions. |
| `SCR-04` | **Side-by-Side Comparison** | Modal dialog comparing Source A vs Source B for a selected invoice, highlighting field deltas with color-coded difference chips. |
| `SCR-05` | **Reports & Export** | Export hub supporting multi-tab Excel workbooks, itemized discrepancy CSVs, and audit trail summaries. |
| `SCR-06` | **Settings** | Configuration for tax tolerances (taxable, tax components), fuzzy matching thresholds, theme, and default export paths. |
| `SCR-07` | **About** | Application version information, license, contributor credits, and link to GitHub repository. |
