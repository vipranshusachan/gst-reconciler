# Installation Guide for Windows

## System Requirements

* **Operating System**: Windows 10 (64-bit) or Windows 11 (64-bit).
* **RAM**: 4 GB minimum (8 GB recommended for 50,000+ invoice datasets).
* **Disk Space**: 150 MB free disk space.
* **Administrator Rights**: Not strictly required (can be installed for current user or all users).

---

## Step-by-Step Installation

1. Download `GSTReconciler-Setup-v1.0.0.exe` from the official GitHub Releases page.
2. Double-click the installer.
3. If Windows SmartScreen displays a warning, click **More info** and then **Run anyway**.
4. Choose whether to create a Desktop shortcut.
5. Click **Install**.
6. Once installation completes, check **Launch GST Reconciler** and click **Finish**.
